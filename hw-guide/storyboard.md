# 컴퓨터 하드웨어 한 번에 총정리 — 기획 · 월드 바이블 · 샷 리스트

## 기획
- **대상**: 게임이 끊길 때 무엇을 바꿔야 할지 모르는, 부품 이름만 들어 본 일반 사용자.
- **메시지**: 본체 안의 부품은 계산(CPU·GPU), 기억(RAM·VRAM·저장장치), 연결과 전기(메인보드·파워·냉각) 세 가지 일을 나눠 맡는다. 주방에 빗대면 요리사, 조리대·냉장고, 바닥·전기.
- **훅**: "램을 늘릴까, 그래픽카드를 바꿀까?" → 마지막에 작업 관리자로 답한다.
- **척추**: op 본체 열기 → cpu → mem(RAM·저장장치) → gpu(GPU·VRAM) → base(메인보드·파워·냉각·케이스) → fin(끊길 때 무엇을 볼까 + 정리).
- **이음(쿠션)**: op08, cpu08–09, mem05, mem10, mem15–17, gpu10–11, base04–04b, base09–09b, base13.
- 길이는 정하지 않음(71큐).

## 월드 바이블
**세계**: *밝은 제품 촬영 스튜디오.* 아주 밝은 회백색 바닥 위에 흰 본체 하나가 놓여 있다. 영화 전체가 이 본체 안에서 일어난다. 메인보드는 바닥처럼 누워 있고, 각 장은 보드 위의 한 동네(CPU 자리, 램 줄, SSD, 그래픽카드, 파워)다. 카메라는 보드 위를 날아 다음 동네로 간다 — 장이 바뀌어도 세계는 하나.
**재질**(three.js, 코드로 만든 형상): 무광 흰 플라스틱(케이스, 둥근 모서리 + 베벨), 은색 금속(CPU 뚜껑, 방열판 핀), 파스텔 컬러 플라스틱(부품 덮개), 반투명 유리(케이스 윗판), 연한 세이지색 기판(배선 무늬는 캔버스 텍스처로 구움). RoomEnvironment 반사로 제품 사진처럼 부드럽게.
**키 라이트**: 왼쪽 위의 큰 소프트박스(디렉셔널 라이트 + 부드러운 그림자). 모든 장에서 같은 방향, 장마다 색만 아주 살짝(데이터가 흐를 때 부품 색의 발광).
**깊이**: 바닥(먼 배경, 안개로 배경색에 녹음) · 본체와 보드(중경) · 떠오른 부품(전경, 카메라 가까이).
**팔레트(색 하나에 역할 하나)**: CPU 코랄 `#ff6b4a`, RAM 하늘 `#3d8bff`, 저장장치 민트 `#19b48a`, GPU 보라 `#7a5cff`(VRAM 연보라 `#b9a6ff`), 파워 앰버 `#ffb020`, 냉각 청록 `#2bc0e4`, 글자 남색 `#1b2130`, 배경 `#f3f5f8`.
**글자**: Pretendard 800 남색, 숫자는 크게. 부품 이름표는 3D 위치에 붙어 따라다니는 작은 점 + 이름(부품 색) + 주방 비유(회색).
**돌아오는 물체**: 데이터 큐브 — 작은 정육면체가 저장장치 → RAM → CPU, VRAM ↔ GPU로 흐른다. 속도·크기·사라짐을 모두 이 큐브로 보여 준다.
**카메라**: 위에서 비스듬히 내려다보는 제품 촬영 앵글(fov 28). 부품 이야기 = 그 부품으로 다가감, 정리 = 전체로 물러남. 흔들림 없음.
**시그니처 전환**: *들어 올리기.* 장의 주인공 부품이 보드에서 천천히 떠올라 카메라 앞으로 오고, 장이 끝나면 제자리로 내려앉는다.
**지난 영상과 다르게**: 어두운 실리콘·캔버스 2D(GPU 영상), 갈색 흙 단면(흙 영상) → 밝은 흰 스튜디오, 실제 3D, 부드러운 그림자.

## 샷 리스트(요약)
- op01–02 닫힌 흰 본체, 위에서. 질문 세 개가 글자로 떠오름. op03–04 유리 윗판이 들려 나가고 카메라가 안으로. op05 세 가지 일: 부품들이 색으로 세 무리(계산/기억/연결)로 차례로 빛남. op06–07 주방 비유 이름표. op08 CPU 쪽으로 이동.
- cpu01–02 냉각기가 위로 들리고 CPU 칩이 보임. cpu03–05 칩이 떠올라 커지고 뚜껑이 투명해지며 코어 블록이 6 → 24개로. cpu06–07 박자 링이 칩에서 퍼짐, 「50억 번」. cpu08–09 칩이 큐브를 기다리며 비어 있음 → RAM 쪽으로 시선.
- mem01–04 RAM 두 줄, SSD 빛남, 큐브가 SSD → RAM → CPU로 흐름. mem05–07 「수십 ns」 vs 「수십 µs」, 큐브 속도 차이. mem08–09 32개 큐브 vs 1000개(10×10×10) 큐브 탑. mem10–11 전원이 꺼지듯 어두워지며 RAM 큐브만 사라짐. mem12–14 하드디스크가 옆에 나타나 원판이 돎, 큐브 흐름 속도 비교 「200 vs 7000 MB/s」. mem15 전체로 물러나 CPU–RAM–저장장치 거리.
- gpu01–03 그래픽카드 덮개가 위로 분리, GPU 칩 위 작은 코어 수천 개, 「16,384」. gpu04–05 VRAM 칩 12개 빛남. gpu06–07 VRAM ↔ GPU 굵고 빠른 큐브 흐름 vs RAM으로 가는 가는 길. gpu08–09 VRAM이 차오르고 넘친 큐브가 먼 RAM으로, 「끊김」. gpu10–11 전체로.
- base01–03 보드 배선이 빛으로 이어짐. base04–08 파워 상자 강조, 교류 물결 → 직류 직선, 「12V·5V·3.3V」, 와트. base09–11 CPU·GPU가 주황으로 달아오르고 팬이 돌며 바람 줄기, 식음. base12 케이스 벽과 윗판이 돌아옴. base13 전체.
- fin01–07 작업 관리자 같은 큰 퍼센트 숫자와 해당 부품의 빛: CPU 100%, RAM 가득, VRAM 가득, GPU 100%, 로딩. fin08–10 모든 부품 위에 비유 이름표가 차례로. fin11 본체 전체, 마지막 정지.
