# 서낭나무 — 진행상황

- 2026-11-21: 사용자 지시("끝나면 b안 c안도 각 스타일에 맞는 lemo opuscar 스킬에 맞춰 진행해")에 따라 후보 C 「서낭나무」를 Lemo-Opuscar **Chinese Ink Wash**(`ink-wash`)로 본 제작. 「막차」와 같은 서하·무진, 같은 목소리.
- 영상 렌더링 없음(HTML만). 정지 화면 확인은 still.mjs → tools/look.py 시트로만.

## 만든 것
- **TREATMENT.md**: 구조 3안 중 "걸개그림(세로 족자)" 선택 — 하늘(크레인) → 나무 → 땅속(뿌리와 아귀) → 다시 삽날 위로. 처음과 끝은 같은 구도(빈터의 나무). 빨강은 하나: 서하 손목의 붉은 실(+ 자막의 붉은 네모, 한글 낙관). 오색 천은 먹의 농담으로만.
- **대사 18줄**(lines.json, 대사만): 서하 Chirp3-HD Kore · 무진 Fish "70대 노스님" · 현장소장 Chirp3-HD Orus(새로 추가) · 신이 내린 서하(g1)는 서하 목소리 + 5반음 낮춘 같은 목소리 겹(mix.py). 음성 인식 불일치 0(m1 "서낭"→"선악", m2 "넋"→"넉"은 인식기 어휘 문제로 asr 필드에 기록).
- **시간표**: story.js, 137 s, 13샷. 박이 있는 곳(걸음·굴착·싸움·작두)은 0.75 s(80 bpm).
- **그림**: ink.js·comp.js(데모의 붓·화선지 합성기 그대로), figure.js(데모 hero 개조: 서하 긴 머리·붉은 실, 무진 민머리·염주, 소장 안전모), site.js(공사장 세계: 크레인·아파트 골조·펜스·나무·오색 천·굴착기·아귀, 땅속 층), shots.js(13샷 + 먹 번짐 전환 5곳), title.js(나눔붓글씨 골격을 따라 붓으로 쓰는 세로 제목), seal.js(한글 백문 낙관 "서낭"), subs.js(제발 자막: 송명체, 붉은 네모, 글자 둘레의 먹을 걷어 내 그림 위에서도 읽힘).
- **음악**: music/score.py — 거문고처럼 낮게 뜯는 줄(라이브러리 guqin 물리 모델), 청이 떠는 대금 같은 관, 장구(궁·채), 큰북, 징, 꽹과리, 방울 동기(서하의 테마). 방울이 죽는 순간(88.6 s) 음악이 끊김, 결단 전 112.4–113.9 s 진짜 정적(0), 비백에 징 한 번. 샘플·녹음 없음.
- **소리**: mix.py — 밤바람·공사장 웅웅거림·땅속 압력·새벽 공기, 효과음(먹 방울, 붓, 천 펄럭임, 낙관, 자갈 걸음, 방울, 죽은 방울, 먹 번짐, 굴착기 엔진·삽·뿌리 뜯김·땅 갈라짐, 아귀의 숨·이빨, 염주 타격, 가르기, 맨발로 쇠 밟기, 비백, 빨려 듦, 땅 닫힘, 새벽 새). 정적 구간에는 물방울 하나만.
- **글꼴**: 부분 글꼴(송명 134자 26 KB, 나눔붓글씨 4자 2 KB), 빠진 글자 0.
- **플레이어**: tools/viewer.html + tools/build_viewer.sh(esbuild 한 파일, mix.mp3 −14 LUFS). 소리가 시계, 누르면 소리와 함께 시작, 프레임마다 try/catch, 불러오는 동안 모든 샷을 한 번씩 그림, 표지는 제목+낙관(14.4 s).
