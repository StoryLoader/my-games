## 만든 것
- 대사 13줄: 내레이터 Algenib, 하루 Leda, 노을 Fish "걸걸한 할머니". ASR 검사 불일치 0.
  - h3는 "안 돼…!"를 읽으면 "느낌표"를 소리 내어 읽어서 녹음 원문을 "안 돼!"로(화면 대화창은 "안 돼…!").
  - n1은 "잠들지"가 흐리게 들려 "평생 한 번도 잠들지 못한 파수꾼, 노을 할머니가…"로 다시 녹음.
- 장면 13컷: 금빛 꿈(그림자가 도는 새 빛) → 지도에서 나방이 금빛 쪽으로 방향을 틈 → 제목 → 창가의 하루 → 종 줄과 매듭(천장 구멍으로 드는 달빛) →
  언덕에서 등불로 나방 떼를 빨아들임(게이지) → 덧문, 열쇠 구멍의 나방, 몸을 날려 잡기 → 보랏빛으로 뒤덮인 창, 어깨에 얹은 손, 정적 →
  종 줄을 풀고 당김 → 종(흔들림 1회) → 지도: 종소리 파동이 지나며 창문이 하나씩 켜지고 마을 사람 등불이 탑으로 → 코 고는 노을 → 새벽 계단.
- 탑 방은 이 영화에 맞게 다시 배치: 노을의 의자 뒤에 창, 그 옆에 열쇠 구멍 문, 가운데 받침대에 종 줄.
- 마을 사람: 잠옷과 수면 모자를 쓴 픽셀 인물 10명(8가지 색, 넷째마다 물동이).
- 음악(music/score.py): 금빛 꿈의 첼레스타 → 나방이 방향을 트는 트레몰로 → 순찰의 8분음 → 압박 → 결정의 정적(68.8–74 s, 유리 두드림만) →
  종 직전 숨 멈춤 → 종 뒤 D장조 → 새벽 자장가.
- 소리(mix.py): 합성 청동 종(D, 부분음 10개, 11초 감쇠), 코골이, 덧문을 두드리는 나방, 나방 떼 날갯짓(덧문 닫히면 먹먹하게), 마을 사람 문·발소리.
