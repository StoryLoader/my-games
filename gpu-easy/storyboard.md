# 세상에서 가장 이해하기 쉬운 GPU 만드는 법 — 기획 · 월드 바이블 · 샷 리스트

## 기획
- **대상**: GPU라는 말은 들어 봤지만 안에서 무슨 일이 일어나는지 모르는 일반 시청자.
- **메시지**: GPU는 전기 스위치로 만든 작은 계산기를 수천 개 복사해 메모리 옆에 놓고, 그 설계도를 빛으로 모래 위에 새긴 것이다.
- **훅**: 지금 보는 화면의 점 830만 개를 1초에 60번 칠하는 일 — 그걸 해내는 부품을 직접 만들어 본다.
- **비율** 16:9. 길이는 정하지 않음(51큐).
- **척추**: 1 op 무슨 일을 하나 → 2 sw 계산기 하나 → 3 cp 수천 개 복사 → 4 fb 모래에서 칩으로 → 5 ai 왜 인공지능까지.
- **이음(쿠션)**: op07, sw12–sw13, cp09–cp10, fb13, ai06.

## 월드 바이블
**세계**: *빛나는 실리콘의 내부.* 영화 전체가 하나의 칩 표면 위에서 일어난다. 거울처럼 매끈한 실리콘 웨이퍼, 보는 각도에 따라 보라·청록으로 번지는 얇은 막의 무지개 광택, 그 위에 구리색 배선이 도시의 도로처럼 깔려 있다. 카메라는 화면의 점 하나에서 출발해 칩 안으로 내려가고, 마지막에 다시 화면으로 올라온다.

**장마다의 자리**
| 장 | 자리 | 물체 | 키 라이트 |
|---|---|---|---|
| 1 op | 모니터 표면의 극접사 → 화면 전체 | 빨강·초록·파랑 세 줄의 하위 픽셀, 위에서 아래로 훑는 새로 고침 | 화면 자체의 빛(백라이트) |
| 2 sw | 실리콘 표면 위 한 칸 | 트랜지스터(문이 달린 통로), 전자 알갱이, 1·0 램프, AND·XOR 방 | 차가운 흰빛, 왼쪽 위 |
| 3 cp | 칩 전체로 물러남 | 금빛 코어 타일이 1→2→4→…→수천으로 복사, 옆의 메모리 블록, 넓은 버스 | 위에서 내리는 흰빛 + 코어마다 작은 발광 |
| 4 fb | 공장 | 모래 알갱이 → 빛나는 녹은 실리콘 → 잉곳 → 무지개 웨이퍼, 보라 빛줄기와 마스크, 주석 방울과 레이저 섬광, 다이아몬드 톱 | 극자외선 보라 |
| 5 ai | 다시 칩 위 | 숫자 표(행렬)가 코어 격자로 흘러듦, 텐서 코어 | 따뜻한 흰빛 → 마지막 화면 빛 |

**재질**: 실리콘(어두운 남청, 미세 결정 노이즈 + 얇은 막 간섭색), 구리 배선(베벨 + 하이라이트), 금빛 코어 타일(브러시드 메탈), 유리 같은 웨이퍼(각도 따라 무지개). 모두 빌드 시 굽는다(162-relight 기법, `js/world.js`).
**팔레트**: `--si #0d1424`(실리콘), `--cu #e08a4a`(구리·배선), `--core #f2c14e`(코어·"지금"), `--on #5fe3c0`(켜짐=1), `--euv #9b7bff`(극자외선), `--fg #eef2fa`.
**글자**: 히어로는 Pretendard 800(숫자) · Gowun Batang 대신 이번엔 **기하학적 산세리프 한 벌**(Pretendard)로 — 흙 영상과 달리 "새겨진 금속" 질감: 글자에 구리 배선 텍스처를 채우고 위 모서리 밝은 테.
**돌아오는 물체**: 화면의 점 하나(픽셀). 1장에서 시작, 3장에서 코어에 나눠지고, 5장에서 숫자 칸이 되었다가, 마지막에 다시 화면의 점.
**카메라**: 확대·축소(스케일 여행)가 기본 언어. 푸시인 = 더 작은 부품으로, 풀아웃 = 전체로.
**시그니처 전환**: *노광 스윕.* 보라 빛띠가 화면을 왼쪽에서 오른쪽으로 훑으며 다음 장을 "찍어" 낸다(빛을 받은 곳부터 새 장면이 드러남).
**지난 영상과 다르게**: 흙(따뜻한 갈색, 손글씨, 명조) → 실리콘(차가운 남청·무지개, 금속 글자, 산세리프), 삽질 컷 → 노광 스윕.

## 샷 리스트(요약)
- op01 ECU 하위 픽셀 → op02 풀아웃해 화면 전체, 「830만」「×60」 → op03 「5억」 카운터 → op04 칩이 화면 뒤에서 떠오름 「GPU」 → op05–06 세 단계 아이콘이 화면 위 점으로 차례로(계산기·복사·모래) → op07 칩 표면으로 푸시인, 노광 스윕.
- sw01 실리콘 위 트랜지스터 하나 CU → sw02 문이 열리면 전자가 흐름 → sw03 램프 1/0 → sw04 스위치 둘이 묶여 방(게이트) → sw05 AND, sw06 XOR(입력 램프 조합을 차례로) → sw07–09 1+1: 두 입력 켜짐 → XOR 0, AND 1 → 「10」 「= 2」 → sw10 칸이 이어져 줄 → sw11 금빛 코어 타일로 접힘 → sw12–13 코어 하나 풀아웃, 노광 스윕.
- cp01–02 CPU: 큰 코어 16개 블록 → cp03–04 GPU: 코어 타일이 기하급수로 복사, 카운터 16,384 → cp05 화면 격자의 점들이 코어로 날아가 동시에 켜짐 → cp06 한 개의 큰 빛 vs 수천 작은 빛 → cp07 코어들이 깜빡이며 대기 → cp08 메모리 블록과 넓은 버스, 데이터 알갱이 흐름 → cp09–10 설계도(청사진 선)가 종이처럼 접혀 모래로, 노광 스윕.
- fb01 모래 알갱이 ECU → fb02 「99.9999999%」 → fb03 잉곳이 녹은 실리콘에서 올라오고 웨이퍼로 썰림 → fb04–05 마스크와 빛, 무늬가 찍힘 → fb06 「13.5 nm」 → fb07 주석 방울과 레이저 섬광 → fb08 층이 쌓임 + 카운터 「수천 단계 · 3개월」 → fb09 톱 자국, 칩 하나가 들림 → fb10–11 「800억」 → fb12 기판·메모리와 패키지 → fb13 노광 스윕.
- ai01–02 숫자 표(행렬) → ai03 칸들이 흩어져 코어에 → ai04 점과 숫자가 같은 격자 → ai05 텐서 코어 블록 → ai06–08 칩에서 풀아웃해 화면으로, 마지막 점 하나.
