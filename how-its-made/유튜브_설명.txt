· AI에게 "주제"만 줬더니 영상이 나왔다 | 스킬 찾기부터 내보내기까지

[설명]
「반도체 vs 우주선, 무엇이 더 어려울까?」 — 입체 모형이 움직이고, 내레이션과 자막까지 붙은 6분짜리 영상.
이 영상은 편집 프로그램을 한 번도 열지 않고, 터미널에 글 몇 줄을 입력해서 만들었습니다.

그 과정을 처음부터 그대로 따라 할 수 있게 순서대로 보여 드립니다.
스킬을 찾고 → 설치하고 → 말로 주문하고 → 결과를 보며 고치는 네 단계,
그리고 "왜 이게 되는지" 원리까지 설명합니다.

⌨️ 영상에 나온 명령
· Claude Code 설치 (맥 · 리눅스 · WSL)
  curl -fsSL https://claude.ai/install.sh | bash
· 윈도우는 먼저 PowerShell에서 WSL 켜기 → 그 안에서 위 명령
  wsl --install
· 실행
  claude
· 스킬 설치
  git clone https://github.com/kstost/script-to-motion.git ~/.claude/skills/script-to-motion
  cd ~/.claude/skills/script-to-motion/scripts && npm install
· 영상 파일로 굽기 (만들어진 영상 폴더 안에서)
  python3 render.py

🧰 준비물
· Claude Code — Claude 유료 요금제 또는 API 요금이 필요합니다
· Node.js, Python, ffmpeg, Chrome
· (목소리 내레이션을 넣을 때) Fish Audio 키와 목소리 ID — 유료 서비스. 없으면 화면만으로 된 영상을 만들 수 있습니다

🔎 스킬을 고르는 기준 네 가지
· 설명서(README)가 충실한가
· 최근에 고쳐졌는가
· 라이선스가 무엇인가
· 내 목적에 맞는가 — 별 개수보다 이것이 먼저입니다

💬 실제로 입력한 요청
· "주제 : 반도체 기술 vs 우주선 기술, 무엇이 더 어려운가?"
· (첫 결과를 보고) "three.js로 입체적이고 멋지게 만들어라. 반도체쪽은 라이트한 테마로 우주쪽은 다크한 테마로 잘 이해되게"
가장 중요한 요령: 한 번에 완벽하게 주문하려 하지 말고, 결과를 보고 고칠 점을 말하세요.

💡 원리 세 가지
① 이 영상은 영상 파일이 아니라 웹페이지입니다. 글자·그림·3D 모형이 전부 코드로 적혀 있습니다.
② 대본이 시간표가 됩니다. 한 줄씩 녹음하면 줄마다 시작·끝 시각이 남고, 화면은 그 시각을 받아 움직입니다.
③ 화면의 모든 모양은 "지금이 몇 초인지"로 정해집니다. 그래서 한 장씩 찍어 MP4로 구울 수 있습니다 (1초에 60장, 6분 23초면 약 2만 3천 장).

⚠️ 꼭 기억할 것
숫자와 사실, 화면의 글자는 사람이 다시 확인해야 합니다. AI가 조사해도 틀릴 수 있습니다.
