## 기획
- **대상**: 터미널을 거의 써 보지 않은 사람. 「반도체 vs 우주선」 같은 영상을 자기도 만들어 보고 싶은 사람.
- **메시지**: 편집 프로그램 없이, 터미널의 Claude Code에 글로 주문해서 만들었다. 순서는 ① 스킬 찾기 ② 설치 ③ 말로 주문 ④ 확인·내보내기. 되는 이유는 "영상이 웹페이지이고, 대본이 시간표이며, 화면이 시간 t로 정해지기 때문".
- **사용자 지침**: 터미널 Claude Code CLI 기준 · 깃허브에서 스킬 찾는 법부터 순서대로 · 스킬 소개 · 제작 원리 · 완성 영상을 처음과 마지막에.
- **척추**: op 완성 영상(발췌 3개) → 준비물(Claude Code 설치) → STEP 1 스킬 찾기 → STEP 2 설치(+Fish Audio 키) → 스킬 소개 → STEP 3 주문(실제 입력 두 줄, 고쳐 가며) → 원리 ①②③ → STEP 4 확인·내보내기 → 정리 + 완성 영상(발췌 2개).

## 소리
- 배경음악 없음(따라 하는 튜토리얼). 효과음은 전부 sfx/make_sfx.py로 합성(녹음·내려받은 소리 없음). 2026-11-14 사용자 요청("효과음은 하나도 없어서 지루한 느낌 … 효과음 추가해")으로 종류를 늘리고 키움:
  - 명령이 쳐질 때 타자 소리(keys_a/keys_b 번갈아) + 끝에 엔터(enter) · 단계가 바뀔 때 두 음 종(step) · 왼쪽 제목이 바뀔 때 스윽(whoosh)
  - 카드·칩이 튀어나올 때 팝(pop) · 줄·행이 나타날 때 틱(tick) · 초록 결과 줄과 고른 스킬에 완료음(ok)
  - 한 장씩 찍는 장면에 셔터(shutter) · 되감기에 테이프 소리(rewind) · 멈춤 문제·주의에 낮은 버즈(buzz) · 완성 영상이 나타날 때 낮은 임팩트(hit)
  - 음량: 내레이션보다 6~10 dB 낮게(구운 MP4에서 측정). 같은 순간에 겹치면 큰 것 하나만, 단계 종 위에는 다른 소리를 얹지 않음(scenes.js 끝부분).
  - 각 효과음 파일은 앞 30 ms·뒤 120 ms 무음을 둠(재생기가 조금 늦게 시작해도 첫 소리가 잘리지 않게).
- 내레이션 빠르기: 2026-11-14 사용자 요청("나레이션은 그대로가되 배속을 살짝 높이고" — 목소리가 졸리다)으로 같은 녹음을 음높이 그대로 1.12배 빠르게 함(sfx/tempo_takes.py, ffmpeg rubberband). 스킬의 기본 규칙(내레이션은 항상 1배)과 다르며, 그래서 check.mjs가 ".tts-cache가 tts.mjs가 쓴 것과 다르다"고 보고함 — 사실 그대로의 보고이고 generated.json은 고치지 않았음. 원본 녹음은 프로젝트 밖(~/.cache/tempo-takes/how-its-made)에 보관.
- 발음: "3D"는 "쓰리 디"로 읽음(사용자 요청 2026-11-14).
