# 스토리보드 — 항우 vs 여포 (다큐멘터리, 기승전결)

## 기획
- 요청(2026-11-17): "여포vs항우, 다큐멘터리식으로 실제 역사기반으로 이야기를 흥미롭게 기승전결식으로 제작해줘"
- 보는 사람: 두 이름은 들어 봤지만(게임·소설·웹툰) 실제 역사는 잘 모르는 사람. 고대 중국사 지식 없음 → 나라·사람·벼슬·용어는 처음 나올 때 한 줄로 설명.
- 질문(척추): "둘이 싸웠다면 누가 이겼을까?" → 기록으로는 판정 불가 → 장수로서의 기록은 항우가 앞섬 → 그런데 둘 다 졌다 → 왜? 사람을 얻지 못했다 → 천하라는 솥은 혼자 들 수 없다.
- 구조: 프롤로그(질문과 약속: 소설 말고 역사책) → 기(세상에 나오다) → 승(막을 수 없는 힘) → 전(금이 가다) → 결(마지막 장면) → 판정. 매 장 안에서 항우(시간이 앞섬) → 여포 순서. 장마다 닫기·전환·열기(쿠션).
- 정직: 숫자는 "옛 기록의 숫자", 소설 장면(방천화극·초선·삼영전)은 소설이라 밝힘. 원문 요지는 research.md.
- 내레이션: Google Cloud TTS(ko-KR-Chirp3-HD-Sadaltager, 사용자가 2026-11-16 고른 목소리). 음악 없음(설명형 다큐) — 효과음은 코드로 합성.

## 월드 바이블 — 「먹의 산수, 사백 년」
- **세계**: 한 장의 끝없는 수묵 산수화. 화선지 위에 먹으로 그린 산·안개·강·성·사람이 깊이를 가진 층(plane)으로 서 있고, 카메라는 그 속을 지나간다. 화면 전체가 종이 결을 가진 한 장의 그림이다.
  - 두 골짜기: **항우의 골짜기**(왼쪽 세계, 기원전)는 낮게 뜬 청동빛 해가 안개를 금빛으로 물들인다. **여포의 골짜기**(오른쪽 세계, 서기)는 희고 차가운 달·겨울 해, 그리고 유일하게 붉은 것 — 적토마의 붉은 먹.
  - 둘 사이에는 흐르는 안개의 강, 「사백 년」. 두 사람은 이 안개를 사이에 두고 끝내 만나지 못한다(프롤로그 히어로 프레임).
- **장소(장)**: 프롤로그 = 안개 강을 사이에 둔 두 능선 / 기 = 강동의 강가와 북쪽 초원 / 승 = 거록의 강(배와 솥), 팽성의 강, 흑산의 검은 산, 진영 문 / 전 = 금이 간 그림: 신안의 구덩이, 홍문의 막사, 불타는 함양, 물에 잠긴 하비 / 결 = 해하의 밤 진영, 오강 나루, 겨울 백문루 / 판정 = 두 사람이 사라진 산수, 그리고 여럿이 함께 드는 청동 솥.
- **반복되는 물건**: 청동 솥 **정(鼎)** — 실제 3D, 녹청이 낀 청동, 따뜻한 키 라이트를 받는 유일한 금속. 젊은 항우가 들어 올린 솥(ki06) → 사람을 삶은 솥(jn12, 같은 물건의 어두운 메아리) → 여럿이 함께 드는 천하의 솥(ep15–16). 여포에게는 **극(戟)** — 쇠로 된 갈래 창(sg23 동탁이 던진 수극, sg39–40 진영 문의 극).
- **빛(장마다 키 라이트 하나)**: 프롤로그 = 안개 뒤의 흰 해 / 항우 장면 = 낮은 청동빛 해(왼쪽 위) / 여포 장면 = 차가운 흰 해·달(오른쪽 위) / 거록·함양 = 불빛(아래에서) / 해하 = 달빛 + 적 진영의 횃불 고리 / 오강 = 새벽 / 하비·백문루 = 흐린 겨울빛 / 판정 = 솥 위로 떨어지는 한 줄기 빛.
- **재질**: 화선지(섬유와 번짐이 있는 따뜻한 종이), 먹(번짐 가장자리·마른 붓 자국·농담), 청동(녹청과 금빛 하이라이트, 실제 3D 조명), 쇠(극), 비단 깃발, 물(먹으로 그은 물결).
- **깊이**: 가까운 바위·나뭇가지(진한 먹, 흐림) → 인물 → 중경의 산 → 먼 산(연한 먹, 안개에 묻힘). 층 사이마다 안개 띠. 대기원근: 멀수록 종이색에 가까워진다.
- **팔레트**: 종이 `#efe6d4`, 먹 `#151315`(진)–`#7d7a76`(연), 청동 `#b08a3e`·녹청 `#4f7a6a`(항우·정), 적토 `#a3302a`(여포·적토마만), 인주 `#c0392b`(낙관·장 표시), 불 `#e8873a`(거록·함양·해하 횃불만).
- **글자 = 그림의 일부**:
  - 산수화의 제발(題跋)처럼, 인용과 원문은 하늘의 빈자리에 **세로쓰기**로 먹으로 쓰이고 낙관이 찍힌다(한자: LXGW WenKai TC, 한국어 번역: Song Myung).
  - 큰 말(파부침주, 사면초가, 56만 대 3만 …)은 붓으로 쓰는 듯 획이 나타나는 **붓글씨**(Nanum Brush Script / 한자는 WenKai)로 그림 속에 크게.
  - 장 표시는 **인주 낙관**(起·承·轉·結)이 종이에 쾅 찍힌다.
- **카메라**: 다큐멘터리의 느린 카메라. 긴 렌즈(fov 24–32)로 층을 압축하고, 옆으로 흐르는 트래킹(시간은 화면 왼쪽→오른쪽), 말이 가리키는 대상에 천천히 다가가는 푸시인, 전체를 말할 때 안개 위로 오르는 크레인. 흔들림 없음.
- **시그니처 전환**: **먹물 한 방울** — 위에서 떨어진 먹이 종이에 번져 화면을 덮고, 번짐이 걷히며 다음 장소가 드러난다(장과 시대가 바뀔 때). 같은 장 안에서는 안개를 지나가는 카메라.
- **이번 작품에서 바꾼 것**(앞 작품들과 다르게): 「남은 길」의 해질녘 툰 셰이딩·주황 하늘·필름 그레인 대신, 단색 수묵 + 종이 + 두 가지 강조색(청동, 적토). 가로 자막 타이포 대신 세로쓰기 제발과 낙관. 카메라는 인물 클로즈업 위주 대신 산수의 층을 지나는 트래킹.

## 소리(코드로 합성, 음악 없음)
- 바람·안개(낮은 숨결), 먹물 떨어짐(전환), 낙관 찍는 소리(장 표시), 말발굽, 북(전투), 쇠 부딪침, 물(강·수공), 불(거록·함양·해하 횃불), 화살(원문사극), 줄 조이는 소리(백문루), 그리고 청동 솥의 낮은 울림(정이 나올 때마다 같은 소리).

## 확인
- 첫 청취자 검토 4회(8 → 7 → 2 → 마지막 고친 줄 다시). 원문 사이트는 이 세션에서 열리지 않아 검색 요약과 기존 지식으로 대조(research.md).
- render.py 시트: 10초 간격 전체 3회 + 고친 컷 시트. 겹침 레이어(먹물·금) 캔버스가 비워진 뒤에도 남던 문제 → 매 프레임 갱신.
- 아트 디렉터 검토 2회: 1회차 2~3점 → 흑산 돌격(말 높이 트래킹), 하비 수공(성벽을 타고 오르는 물), 백문루(로우앵글·역숏·밧줄 클로즈업), 엔딩(열 사람이 함께 드는 솥), 두루마리(이름이 불릴 때 펼침, 평가는 한 권씩), 금(하늘의 가는 종이 금), 빈 프레임 채움, 숫자는 붓글씨.
