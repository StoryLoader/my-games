# 민준이의 섬 (`index.html`) 쉬운 설명 + 보안 진단

> 작성일: 2026-10-07 · 대상 파일: `index.html` (파일 하나에 HTML, CSS, JS가 모두 들어 있어요)

웹페이지는 **집 짓기**와 비슷해요.

| 부분 | 비유 | 하는 일 |
|---|---|---|
| HTML | 🧱 뼈대 | 무엇이 있는지 정해요 (글씨, 버튼, 영역) |
| CSS | 🎨 꾸미기 | 어떻게 보일지 정해요 (색, 크기, 위치, 애니메이션) |
| JS (자바스크립트) | ⚙️ 동작 | 누르거나 움직일 때 무슨 일이 일어날지 정해요 |

---

## 1. 뼈대 (HTML)

`<body>` 안에 위에서 아래 순서로 놓여 있어요.

1. **노란 환영 영역** (`.welcome`): "어서오세요! 👋" 글씨와 **시작하기** 버튼
2. **시작하기 팝업** (`#startPop`): 버튼을 누르면 뜨는 환영 상자. 처음에는 숨겨져 있어요.
3. **하늘 + 섬 화면** (`<section class="hero">`)
   - `#sky`: 유성우가 그려지는 하늘
   - `<canvas id="scene">`: 3D 섬이 그려지는 도화지
   - 제목 "민준이의 섬"과 설명 한 줄
   - 나무 표지판 버튼 5개 (`.tag`): 민준, 건축, 서바이벌, 축구, 치킨
   - 이야기 패널 (`#panel`): 표지판을 누르면 열려요
   - 안내 문구와 "아래로 파 내려가기" 버튼
4. **땅속 층** (`<main id="dig">`): 흙, 돌, 깊은 돌, 물, 다이아 층. 층마다 민준이에 대한 사실이 한 줄씩 있어요.

> 💡 `<button>`은 누를 수 있는 것, `<p>`는 글 한 문단, `<section>`은 구역을 뜻해요.

## 2. 꾸미기 (CSS)

`<style>` 안에 있어요.

- **색 이름표** (`:root`): `--blue` 같은 색 이름을 한 번 정해 두고 여러 곳에서 써요. 색을 바꿀 때 한 곳만 고치면 돼요.
- **글꼴**: 제목은 굵은 `Black Han Sans`, 본문은 `Do Hyeon`이에요. 구글 폰트에서 불러와요.
- **배경**: 하늘은 흰색에서 하늘색으로 이어지는 그라데이션(`linear-gradient`)이고, 환영 영역은 노란 그라데이션이에요.
- **입체 글씨**: `text-shadow`를 여러 겹 쌓아서 블록처럼 두꺼운 글씨를 만들어요.
- **픽셀 그림 무늬**: 나무판, 흙, 돌 무늬는 JS가 그린 작은 그림이에요. CSS가 그 그림을 바둑판처럼 반복해서 깔아요(`background`). `image-rendering: pixelated` 덕분에 픽셀이 또렷하게 보여요.
- **애니메이션** (`@keyframes`): 환영 영역이 위에서 내려오기(`dropIn`), 유성 날아가기(`shoot`), 골 글씨 튀어나오기(`goalPop`), 이모지 터지기(`pop`)
- **휴대폰 화면** (`@media (max-width: 640px)`): 화면이 좁으면 크기와 위치를 바꿔요.
- **움직임 줄이기** (`prefers-reduced-motion`): 움직임을 싫어하는 사람의 설정을 존중해서 애니메이션을 꺼요.

## 3. 동작 (JS)

`<script>`가 두 개 있어요.

### ① 일반 스크립트

- **픽셀 무늬 만들기**: 16×16 크기의 작은 그림(흙, 잔디, 나무판 등)을 만들어요. 3D 섬과 CSS가 함께 써요.
- **유성우**: 0.15초마다 파란 유성을 하나씩 만들고, 다 날아가면 지워요.
- **이모지 폭죽**: 화면을 누르면 그 자리에서 ⚽💎🍗 같은 이모지가 사방으로 퍼져요.
- **시작하기 버튼**: 누르면 버튼이 보라색으로 바뀌고(`clicked` 클래스 추가) 팝업이 떠요. 바깥을 누르거나 `Esc`를 누르면 닫혀요.
- **스크롤 버튼**: "아래로 파 내려가기"와 "섬으로 올라가기"를 누르면 그 위치로 부드럽게 이동해요.

### ② 모듈 스크립트 (3D, `three.js` 라이브러리 사용)

- **장면 준비**: 카메라, 조명(달빛, 파란빛), 렌더러(그림 그리는 기계)를 만들어요.
- **섬 만들기**: 반복문으로 블록을 원 모양으로 쌓아요. 위는 잔디, 아래로 갈수록 흙, 돌, 깊은 돌이에요.
- **물건 만들기**: 파란 지붕 집, 나무, 모닥불, 좀비, 다이아, 골대, 치킨 테이블
- **치비 민준**: 둥근 상자(`RoundedBoxGeometry`)를 조립해서 만들어요. 머리를 크게, 몸을 작게 만들어 치비 비율이에요.
- **끌어서 돌리기**: 마우스나 손가락을 옆으로 끌면 섬이 돌아요.
- **누르기**: 누른 곳에 물건이 있는지 레이캐스트로 검사해서 그 이야기 패널을 열어요. 레이캐스트는 화면에서 보이지 않는 광선을 쏴서 맞는 물체를 찾는 방법이에요.
- **슛**: 민준이가 골대 쪽으로 돌고, 다리를 휘둘러요. 공이 포물선을 그리며 날아가면 "골!!!"과 폭죽이 터져요.
- **매 순간 그리기** (`frame()`): 1초에 약 60번 섬 회전, 숨쉬기, 눈 깜빡임, 모닥불 흔들림을 계산해서 다시 그려요. 표지판도 물건 위치를 따라가요.

## 4. 보안 취약점 진단

**결론: 위험도 낮음 🟢.** 로그인, 입력창, 서버, 개인정보 저장이 없는 정적 페이지라서 공격받을 지점이 거의 없어요. 다만 외부 파일을 불러오는 부분에서 개선할 점이 있어요.

| # | 항목 | 위험도 | 설명 | 권장 조치 |
|---|---|---|---|---|
| 1 | 외부 스크립트 무결성 검사 없음 | 🟡 중간 | `three.js`를 `cdn.jsdelivr.net`에서 불러와요. 만약 그 서버의 파일이 바뀌면(공급망 공격) 바뀐 코드가 그대로 실행돼요. 모듈과 importmap 방식이라 일반 `<script integrity>`를 바로 붙이기 어려워요. | three.js 파일을 내려받아 `index.html` 옆에 두고 직접 불러오기 (가장 안전하고, 인터넷 없이도 작동해요) |
| 2 | 보안 정책(CSP) 없음 | 🟢 낮음 | 어디서 스크립트를 불러와도 되는지 정하는 규칙이 없어요. 지금은 사용자 입력이 없어서 실제 피해 가능성은 낮아요. | 웹에 올릴 때 `<meta http-equiv="Content-Security-Policy">`로 jsdelivr, 구글 폰트만 허용하기 |
| 3 | 외부 글꼴 요청 | 🟢 낮음 | 구글 폰트를 불러올 때 방문자의 IP 주소가 구글에 전달돼요. 개인정보 측면의 참고 사항이에요. | 원하면 글꼴 파일을 내려받아 직접 제공하기 |
| 4 | 화면에 글 넣는 방식 | ✅ 안전 | 패널 글은 `textContent`로 넣어요. 그래서 글 안에 코드가 섞여도 실행되지 않아요. `innerHTML`, `eval`은 쓰지 않아요. | 지금처럼 유지하기 |
| 5 | 사용자 입력과 저장 | ✅ 안전 | 입력창, 쿠키, `localStorage`, 서버 전송이 없어요. | 해당 없음 |
| 6 | 개인정보 노출 | ✅ 확인 | 페이지에 나오는 정보는 이름(민준), 취미, 좋아하는 음식과 색뿐이에요. 사는 곳, 생일, 학교는 없어요. | 인터넷에 공개할 때 학교, 사진, 연락처는 넣지 않기 |
| 7 | 외부 링크 | ✅ 안전 | 다른 사이트로 가는 링크가 없어요. 예전의 `#` 주소 링크도 버튼으로 바꿔서 `file://` 보안 오류도 없어요. | 해당 없음 |

### 용어 미니 사전

- **CDN**: 여러 사이트가 함께 쓰는 파일을 빠르게 나눠 주는 서버
- **공급망 공격**: 내가 가져다 쓰는 남의 파일을 해커가 몰래 바꿔치기하는 공격
- **CSP**: "이 페이지는 여기서 온 코드만 실행해!" 하고 정해 두는 보안 규칙
- **정적 페이지**: 서버 없이 파일만으로 보이는 페이지
