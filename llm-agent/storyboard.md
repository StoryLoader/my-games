## 월드 바이블 — 파스텔 클레이 스튜디오
- 세계: 이음매 없는 파스텔 스튜디오 바닥 위에, 손으로 빚은 듯 둥글고 매트한 클레이 물체들이 놓인다(전부 three.js 기본 도형으로 이 프로젝트에서 직접 만듦 — js/clay.js). 장마다 스튜디오 색이 바뀐다: 크림(도입) → 하늘(LLM) → 민트(학습) → 버터(역사 1) → 얼음색(겨울) → 복숭아(역사 2) → 라일락(역사 3) → 청록(에이전트) → 분홍(발전) → 크림(마무리).
- 주인공: 클레이 로봇 마스코트 = LLM. 처음엔 팔이 없다(말만 한다). 에이전트 장에서 팔이 생기고 도구·수첩을 얻고 고리를 돈다 — 개념이 캐릭터의 변화로 보인다.
- 재료와 물건: 낱말·핵심어·연도 = 글자가 찍힌 둥근 클레이 블록, 파라미터 = 색색의 다이얼, 점수 = 클레이 기둥, 돈 = 동전 더미, 사진 = 클레이 액자(받침대), 화면 = 둥근 패널(휴대폰·대화창·터미널·브라우저·수첩), 도구 = 돋보기·계산기·폴더·달력·톱니.
- 빛: 왼쪽 위 키 라이트 하나 + 부드러운 그림자(바닥은 그림자만 받는 투명 재질이라 배경과 이음매가 없다) + 약한 환경광.
- 카메라: 장면(세트)마다 다른 각도에서 시작해 머무는 동안 천천히 돌며 다가가고, 말이 가리키는 곳으로 밀고 들어간다. 화제가 바뀌면 이전 세트가 통째로 퐁 사라지고, 카메라가 휙 돌아 다음 세트가 톡톡 올라온다(전환음 slide).
- 글자: 문장은 화면 위 DOM(Pretendard 900, 남색). 핵심어는 클레이 칩 모양. 아래쪽 문장은 둥근 흰 띠 위에 놓아 물체와 겹쳐도 읽힌다. 사진 출처는 왼쪽 아래 작은 표지.
- HUD: 왼쪽 위 = 지금 장의 질문(번호 동그라미), 오른쪽 위 = 연도 레일(1950→2026).
- 금지: 글자를 담는 상자·표·글머리 목록으로 화면을 짜지 않는다. 상자는 세계 속 물건(블록, 패널, 액자, 종이)뿐.
- 이전 판(밤의 박물관, 2D)과의 차이: 어두운 초록·황동·액자 벽 → 밝은 파스텔·클레이·3D 공간. 좌우로 걷는 카메라 → 세트마다 돌고 파고드는 카메라.
