# 진행상황 — 「악몽을 지키는 파수꾼 2 — 반딧불의 밤」 (세로 쇼츠, 2분)

## 사용자 기준 (2026-11-21)
- "악몽을 지키는 파수꾼 2편을 만들어라. 2분으로 쇼츠 세로모드로, 다 만들면 렌더링은 하지 말고 html로만 보고해"
- MP4 렌더 금지(사용자가 지시할 때만). 결과물은 브라우저에서 재생되는 HTML.

## 결정
- 이야기: TREATMENT.md (후보 셋 중 3번 "가두지 않고 돌려보내기"). 1편 마지막 대사로 열고 노을의 "이번엔, 내가 지키마."로 닫음.
- 목소리: 1편과 같음 — 내레이터 Google Chirp3-HD Algenib, 하루 Leda, 노을 Fish Audio "걸걸한 할머니". 15줄, ASR 검사 불일치 0.
- 음악(music/score.py): 하프 혼자 1편의 동기 → 차오르는 피치카토·트레몰로 → 금 가는 순간 41.3 s 완전 정적 → 52.3 s 첫 반딧불의 첼레스타 한 음
  → 반딧불 주제(D 장조) → 마을 지도에서 넓어짐(창문마다 첼레스타 한 음) → 85.5–87.5 s 숨 한 번 → 탑 선반이 열리며 금빛으로 → 새벽 자장가.
- 소리(mix.py): 마을 밤(바람·귀뚜라미, 정적 동안 낮춤)·탑 방·새벽 새(컷보다 먼저), 반딧불 반짝임, 효과음 15종을 그림 이벤트 시각에 합성.
  모든 대사가 음악보다 10 dB 이상 위. 최종 −14 LUFS mp3.
- 글꼴: 2편 대사·자막·카드 글자로 부분 글꼴을 다시 만듦(1편 부분 글꼴에 46자가 빠져 있었음).
- HTML 플레이어: tools/viewer.html + tools/build_viewer.sh (esbuild 한 파일 + mix.mp3). 소리는 재생 버튼을 누르는 그 순간 시작(모바일 허용),
  소리가 막히면 화면을 한 번 더 누르면 켜짐. 소리가 시계라서 그림이 소리를 따라감.

## 상태
- 그림: 세로 정지 화면 30곳으로 흐름 확인(문 앞 → 제목 → 선반 → 순찰 → 가득 참 → 손바닥 변신 → 창문 → 지도 → 탑 → 깨어남 → 새벽).
- 선반 장면 끝(19–23 s): 잠든 노을이 자막 뒤에 가려져 있던 것을 카메라를 일찍 노을 쪽으로 돌려 화면 가운데로 고침, 노을 쪽 보조광을 올림.
- 플레이어 시험(헤드리스 크로미움, 휴대폰 크기 400×760): 콘솔 오류 0, 재생 버튼을 누르면 소리가 바로 시작(8초 뒤 7.99 s), 그림이 소리를 따라감, 글꼴 3종 로드.
