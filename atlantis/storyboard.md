# 스토리보드 — 아틀란티스 전설 (다큐멘터리)

## 기획
- 요청(2026-11-18): "다음 주제는 아틀란티스 전설". 앞 영상(항우 vs 여포)에서 사용자가 요구한 방식을 처음부터 적용: 실제 기록 바탕, 실제 고서·그림·사진 자료, 인물의 말은 각자의 목소리, 효과음은 적재적소.
- 보는 사람: 아틀란티스를 영화·게임·괴담으로 들어 본 사람. 플라톤도 그리스사도 잘 모름.
- 척추(질문): 아틀란티스는 정말 있었나? → 기록은 플라톤 하나 → 그가 그린 제국 → 멸망과 끊긴 문장 → 그 빈자리를 채운 2,400년의 수색(키르허, 도널리, 산토리니, 헬리케) → 플라톤은 왜 썼나(이상 국가 vs 오만한 바다의 제국, 그리고 그의 아테네) → 남은 것은 섬이 아니라 질문.
- 목소리: 내레이터 Algenib(사용자가 고른 진중한 목소리) · 이집트 사제 Rasalgethi · 크리티아스 Charon · 도널리 Iapetus. 말하는 동안 이름과 표시가 화면에.
- 음악 없음, 효과음은 코드로 합성.

## 월드 바이블 — 「청동의 바다」
- **세계**: 깊고 푸른 바다 위(그리고 아래)의 세계. 두 개의 층이 서로를 비춘다.
  1. **바다와 고리의 도시(3D)**: 물의 고리 셋과 땅의 고리 둘로 된 아틀란티스가 실제 3D로 바다 위에 놓여 있다. 성벽은 바깥부터 놋쇠·주석·오레이칼코스, 한가운데 포세이돈 신전. 장마다 시간과 날씨가 바뀐다(정오의 영광 → 폭풍의 밤 → 물속 → 새벽).
  2. **흑회식 항아리(3D)**: 이야기 속 사람들(솔론, 이집트 사제, 포세이돈과 클레이토, 열 왕과 황소, 아테네 중장보병, 제우스)은 고대 그리스 흑회식(검은 형상) 항아리에 그려진 그림으로 등장한다. 항아리가 돌며 장면이 넘어간다 — 그리스인이 자기 이야기를 남긴 방식 그대로.
- **반복되는 물건**: **고리**. 아틀란티스의 동심원(3D 도시) → 키르허 지도의 섬 → 산토리니의 둥근 칼데라(실제 위성 사진) → 마지막에 잔잔해지는 물의 고리.
- **빛(장마다 키 라이트 하나)**: 프롤로그 = 수평선의 해질녘 / 1장 = 사이스 신전의 높은 창에서 내리는 빛(항아리에 떨어지는) / 2장 = 지중해의 정오 태양, 오레이칼코스가 붉게 번쩍 / 3장 = 번개와 폭풍의 밤 / 4장 = 물속으로 비스듬히 내리는 빛줄기, 탐사등 / 5장 = 새벽.
- **재질**: 바닷물(파도·반사, 물속의 일렁이는 빛), 대리석, 놋쇠·주석·오레이칼코스(붉은 금), 테라코타(항아리의 주황) 위 검은 유약, 실제 자료(고지도·책·사진)는 액자 대신 **양피지·석판**에 붙여 놓는다.
- **팔레트**: 심해 `#0b2433`, 바다 `#1e5a73`, 물빛 `#7fc4c9`, 대리석 `#e9e4da`, 오레이칼코스 `#c4623a`(유일한 뜨거운 색), 테라코타 `#c8733a`(항아리), 흑유 `#1a1412`.
- **글자**: 그리스 비문처럼 — 그리스어 대문자(GFS Didot)를 돌에 새긴 듯 넓은 자간으로, 우리말은 Hahmlet(세리프). 큰 숫자(9,000 · 2,400 · 373)는 Hahmlet 굵게, 오레이칼코스 색.
- **카메라**: 바다 위를 낮게 미끄러지는 비행, 운하를 따라 고리 안으로 들어가는 진입, 항아리 둘레를 도는 느린 회전, 물속으로 가라앉는 하강.
- **시그니처 전환**: **물결** — 화면 전체가 수면처럼 일렁이며 다음 장면으로(장이 바뀔 때).
- **앞 작품과 다르게**: 수묵·종이·세로쓰기 대신 바다·금속·항아리 그림, 가로 비문. 붉은 낙관 대신 오레이칼코스 빛.
