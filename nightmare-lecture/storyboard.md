# 「악몽을 지키는 파수꾼은 어떻게 만들어졌나」 — 스토리보드

## 계획

- **시청자**: 클로드 코드를 들어 봤지만 스킬이나 프롬프트 구조는 잘 모르는 유튜브 시청자. 영상 제작 경험은 없어도 된다.
- **메시지**: 한 문장의 부탁이 2분짜리 영화가 된 것은, 일곱 겹의 문서(프롬프트)가 역할을 나눠 맡고 일의 순서를 정했기 때문이다.
- **뼈대** (사용자 기준 1–4):
  1. 오프닝 → **2분 7초 영화 전체**(가로형, 쇼츠와 같은 소리: 내레이션·할머니 목소리·음악·효과음 그대로)
  2. 1장 「레모 오퍼스카는 무엇일까?」 — 스킬 정의, 99개 스타일·15갈래, 2.5D 픽셀 아트 위치, 쓰는 법, ✦ 표시
  3. 2장 「한 문장이 어떻게 영상이 될까?」 — 일곱 겹의 프롬프트(스킬 파일 → 설치 스크립트 → 에이전트 안내문 → 연출 지침서 → 기술 지침서 → 스타일 지침서 → 예시 제작 노트)
  4. 3장 「규칙은 어느 장면이 되었을까?」 — 규칙 → 실제 장면(영화를 그 시각으로 다시 틀어 보여 줌)
  5. 마무리 → **인상 깊은 장면 13초 다시 보기**(하루가 등불을 받아 드는 순간 → 노을이 잠듦 → 새벽, 영화 109.4–122.4 s, 마지막 문장 "아주 좋은 꿈을."까지 끊지 않으려고 10초보다 조금 길게)
- **납품**: HTML만. 사용자가 직접 화면 녹화한다. MP4 렌더링은 사용자가 지시할 때만.

## 월드 바이블

- **세계**: 불 꺼진 작업실의 오래된 **환등기 테이블**. 호박색 등불 하나가 아래에서 켜져 있고, 그 위에 **유리판 일곱 장**이 놋쇠 틀에 끼워져 층층이 떠 있다. 빛이 일곱 장을 차례로 통과해 맨 위 **영사 창**에 그림을 맺는다. 그 그림이 영화다.
  - 은유: 등불 = 일하는 클로드, 유리판 = 프롬프트 한 겹, 영사된 그림 = 영화. 영화 속 파수꾼의 등불과 같은 사물이라 이야기와 강의가 한 세계로 이어진다.
- **빛**: 키 라이트는 아래의 등불 하나(호박색 #ffb357, 따뜻함). 주변은 차가운 남청(#0b1022) 어둠. 빛기둥 속에 먼지가 떠다닌다. 유리판 가장자리가 빛을 받아 반짝이고, 새겨진 글자는 빛이 지나갈 때만 호박색으로 켜진다.
- **재질**: 유리(가장자리 하이라이트, 살짝 푸른 투명), 놋쇠(틀과 번호 탭), 호두나무 테이블, 새겨진 글자(빛을 머금은 홈).
- **깊이**: 앞(초점 흐린 유리 모서리·먼지) / 중(지금 다루는 유리판) / 뒤(나머지 유리판 더미, 등불 빛무리).
- **색**: 남청 어둠 · 호박색 빛(규칙이 켜짐) · 보랏빛(악몽, 영화를 가리킬 때만) · 청록(노을의 망토, 단서 장면에서만).
- **글자**: 제목과 새김 글씨는 고운바탕 Bold(영화의 제목 글꼴과 같은 집안), 작은 표지는 Pretendard 자간 넓게. 글자는 유리에 새겨진 빛으로 그린다. 상자·카드 없음.
- **카메라**: 테이블을 비스듬히 내려다보는 높은 3/4 시점(영화와 같은 문법). 겹을 넘어갈 때는 **유리판을 뚫고 아래로 다이브**(시그니처 전환). 장이 바뀔 때는 영사 창으로 밀고 들어가거나 빠져나온다.
- **소리**: 배경음악 없음(사용자 규칙). 코드로 만든 효과음만 — 등불 점화, 유리판이 놋쇠 틀에 닿는 맑은 소리, 다이브의 바람, 새김 글씨가 켜질 때의 작은 반짝임. 영화 구간은 영화 자체의 소리.
