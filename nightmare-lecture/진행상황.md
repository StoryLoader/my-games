# 진행상황 — 「악몽을 지키는 파수꾼은 어떻게 만들어졌나」 (가로형 롱폼 강의)

## 사용자 기준 (2026-11-18)
1. 악몽을 지키는 파수꾼은 가로형으로, 소리(내레이션·할머니 목소리·음악·효과음)는 쇼츠에 쓴 것 그대로.
2. lemo-opuscar 스킬 소개와 종류 안내 → 1장.
3. 영화가 이렇게 나온 원리(스킬 내부 프롬프트 구성) → 2장(일곱 겹) + 3장(규칙 → 장면).
4. 처음에 2분 풀 영상, 마지막 설명 뒤 인상 깊은 부분 다시 보기 → 하이라이트 13초(영화 109.4–122.4 s, 마지막 문장 "아주 좋은 꿈을."까지 끊지 않으려고 10초보다 조금 길게).
- **렌더링 금지**: HTML로만 완성, 사용자가 직접 화면 녹화. MP4 렌더는 사용자가 지시할 때만.

## 결정
- 영화는 영상 파일이 아니라 **실시간 렌더**: `nightmare-keeper/*.js`를 esbuild로 한 파일(`js/film/nk_film.js`)로 묶어 `NK.render(t)`로 그림. 1920×1080. 소리는 쇼츠 MP4의 AAC 트랙을 비트 그대로 복사(`assets/user/film/film_sound.mp4`).
- 내레이션: Google TTS `ko-KR-Chirp3-HD-Algenib`(아틀란티스와 같은 목소리), `sfx/google_tts_takes.mjs` → `tts.mjs --record-cache`. 64줄, 모든 컷 `ranges: []`(구글 테이크는 문장 단위로 다듬어져 있음; c20 15.7 s의 0.8 s 쉼은 그대로 둠).
- 대본: 첫 청취자 리뷰 7회(서브에이전트) — 마지막 회차 지적까지 반영.
- 효과음: 배경음악 없음(사용자 규칙). `sfx/export_events.mjs`가 장면이 등록한 소리 이벤트를 뽑고 `sfx/make_sound.py`가 합성.
- 검사 도구(errscan·check_fonts 등, `?render` 없는 webdriver)에서는 영화 프레임을 건너뜀(CPU 렌더로 한 장에 수 초). render.py와 일반 브라우저는 그대로 그림.
